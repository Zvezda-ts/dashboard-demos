# Демонстрации дашбордов Татьяны

Интерактивные примеры с вымышленными данными.

- **МойСклад v2** — собственная разработка Татьяны: продажи, валовая прибыль, товары, остатки и план. Это не внедрение у другого клиента и не продукт для селлеров.
- **BrandOS v3** — демонстрационный кабинет бренда на маркетплейсах: юнитэкономика, остатки, продажи, финансы, реклама, поставки, акции, РНП, цены и скидки площадок.

## Просмотр

Откройте index.html или страницу GitHub Pages. Распаковывать и открывать локальную копию нужно целиком. Перед показом нажмите «Вернуть пример».

## Границы демо

Реальные API, реклама и акции площадок не подключены. Управление в BrandOS меняет только локальный будущий сценарий и не переписывает исторический журнал. Условные тарифы и расходы не являются актуальными тарифами площадок. ИИ-подсказки — локальные шаблоны; документы не распознаются. На физическом телефоне проверка не выполнялась. Вымышленные показатели не являются результатами клиентов.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save. Файл .nojekyll оставьте в корне. Не добавляйте сюда исходные выгрузки бизнеса, пароли, ключи, внутренние паспорта и архивы.
